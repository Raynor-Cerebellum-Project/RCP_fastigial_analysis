# RCP_fastigial_analysis in MATLAB

## Overview
This repository contains the analysis pipeline for preprocessing, quantifying kinematics, and neural data for the fastigial experiments.  

[Example final figures: Bert's plots for headturn](https://docs.google.com/presentation/d/1z6fLBiO8Wbell_FSsJK0Mcj66stKMJZmZtJu6tcY7FA/edit?slide=id.g35fb40ee04d_0_42#slide=id.g35fb40ee04d_0_42)

Location: ~cullen_data/Current Project Databases - NHP/2025 Cerebellum prosthesis/Bryan/RCP_fastigial_analysis

The folder structure is as follows:
```
.
├─ analysis_scripts
├─ batch_scripts                            # Pipeline scripts
├─ curation_scripts                         # Visualizing kinematics and OCR frame correction
├─ functions
│ ├─ behavioral_processing                  # Behavioral analysis functions
│ ├─ fr_estimate_kathy                      # Kaiser filter from Cullen lab
│ ├─ neural_processing                      # Neural data analysis functions
│ ├─ stim_preprocessing                     # Stim data processing functions
│ └─ utils
└─ old_code

├─ .gitignore
└─ README.md
```
Outputs:
```
.
├─ data                   # Experimental data folder
│ ├─ Checkpoints          # Intermediate files
│ └─ Figures              # Figures generated by pipeline
```
data and results (output) can be chosen to be other directories in the top of scripts.


## May need to run batch_processing_neural (artifact correction) on the cluster

1. Change session name and input metadata info in each script (control, at rest, trials)
2. Run `~/RCP_analysis/MATLAB/batch_scripts/parse_delays.m`, if the experiment has Random trials but need delay segmentation
3. Run `~/RCP_analysis/MATLAB/batch_scripts/batch_processing_neural.m`
4. Run `~/RCP_analysis/MATLAB/batch_scripts/batch_analyze_behavior.m`
5. Run `~/RCP_analysis/MATLAB/batch_scripts/batch_analyze_with_neural.m`


All_Intan2Bin_w_cal_loop: loops through all intan folders and creates a bin file of data within each folder
Filet_signals: some basic filtering 
Add_intan_index_RWstim: adds intan file indexes to the calibrated .mat files
KiloSort2Stitch_all_cells_fastig: combines output from KS4 and Phy2 (based on indexed cell IDs) and stitches all the good cells into the calibrated .mat file and saves a copy of it.
